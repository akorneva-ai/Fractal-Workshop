# Fractal-Workshop

«Фрактальная мастерская» — интерактивная программа на Python для построения различных фракталов с помощью рекурсивных алгоритмов и библиотеки `turtle`.

Программа объединяет несколько типов фракталов в одном приложении: пользователь выбирает нужный фрактал и задаёт параметры его построения.

## Структура проекта

```text
Fractal-Workshop/
├── main.py
├── fractals/
│   ├── __init__.py
│   ├── basic.py
│   ├── koch.py
│   └── complex.py
└── README.md
```

### `main.py`

Главный файл программы.

Отвечает за:
- главное меню;
- выбор фрактала;
- ввод параметров;
- запуск соответствующей функции;
- переход между фракталами.

### `fractals/basic.py`

Базовые рекурсивные фракталы:

- двоичное дерево;
- фрактал «Ветка».

### `fractals/koch.py`

Фракталы, построенные на основе рекурсивных кривых:

- кривая Коха;
- снежинка Коха;
- кривая Минковского.

### `fractals/complex.py`

Более сложные фракталы:

- ледяной фрактал №1;
- ледяной фрактал №2;
- кривая Леви;
- дракон Хартера–Хейтуэя.

### `fractals/__init__.py`

Инициализационный файл пакета `fractals`, позволяющий использовать его модули в проекте.

## Назначение проекта

Проект предназначен для демонстрации принципов построения фракталов с помощью рекурсии и объединения отдельных алгоритмов в единое интерактивное приложение.
